# ADR-002: Capability-owned persistence

- Status: Accepted
- Owner: `@agent-mail/storage`
- Decision: Use capability-owned storage, numbered migrations, transactions, and parsers from `unknown`.
- Consequence: Persistence invariants and recovery closure have one owner; blobs require digest and size verification.
- Supersession: A replacement must name `ADR-002` and change this record to `Superseded` in the same change.
- Evidence: PLAN.md architecture decisions and F05/F07/F24/F29 controls; prior implementations are evidence-only.
