# ADR-004: IMAP adapter boundary

- Status: Accepted
- Owner: `@agent-mail/imap`
- Decision: Normalize optional IMAP capabilities, status, fetch, IDLE, and authentication errors at the adapter boundary.
- Consequence: Missing fields remain unknown, sparse UIDs are bounded, and provider behavior cannot silently become domain truth.
- Supersession: A replacement must name `ADR-004` and change this record to `Superseded` in the same change.
- Evidence: PLAN.md architecture decisions and F03/F06/F10/F20/F22 controls; prototype fakes are evidence-only.
