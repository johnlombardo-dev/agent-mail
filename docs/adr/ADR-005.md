# ADR-005: Controlled remote effects

- Status: Accepted
- Owner: `agent-maild`, `@agent-mail/imap`
- Decision: Require stored, expiring, frozen-target plans; atomically claim them; persist per-target attempts; keep executor operations internal.
- Consequence: Remote uncertainty is recoverable and bearer clients cannot impersonate the executor.
- Supersession: A replacement must name `ADR-005` and change this record to `Superseded` in the same change.
- Evidence: PLAN.md invariants and F04/F08/F09 controls; prior action implementations are evidence-only.
