# ADR-001: Transport-free domain and shared contracts

- Status: Accepted
- Owner: `@agent-mail/core`, `@agent-mail/contracts`
- Decision: Keep core transport-free and use one versioned Zod/OpenAPI contract registry for daemon and CLI.
- Consequence: Boundary parsing and API/CLI parity are explicit; transport definitions do not leak into core.
- Supersession: A replacement must name `ADR-001` and change this record to `Superseded` in the same change.
- Evidence: PLAN.md architecture decisions; prototype comparisons are evidence-only.
