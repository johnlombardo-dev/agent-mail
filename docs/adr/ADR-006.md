# ADR-006: Bounded public and rendered surfaces

- Status: Accepted
- Owner: `agent-mail`, `agent-maild`, `@agent-mail/contracts`
- Decision: Use schema-driven HTTP/CLI boundaries with bounded streaming, backpressure, stable errors, sanitized rendered mail, and strict CSP.
- Consequence: Slow consumers and hostile content cannot turn public surfaces into unbounded memory or script execution.
- Supersession: A replacement must name `ADR-006` and change this record to `Superseded` in the same change.
- Evidence: PLAN.md boundaries/invariants and F23/F27/F28/F30 controls; prototype output is evidence-only.
