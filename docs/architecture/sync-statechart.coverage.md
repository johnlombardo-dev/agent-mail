## Installed-XState source-exit corpus

XState 5.32.5 is checked in this exact order: source exit actions; transition actions and release-set freeze; target entry; target invoke input capture; source `fromCallback` disposal or `fromPromise` abort notification; target invoke start. Acquisition synchronously registers each deduplicated slot and terminal before the resource becomes live. The first request revokes every registration capability in the exiting source tree; promotion can select only a broader subset of that already-registered tree. A disposer or abort handler holds only `triggerRelease`, so registration after phase freeze is impossible.
