## Accepted issue #196 decisions

`UC01` is resolved by P1-C08-R. Every status and every operation-specific `observed` object includes a required trimmed, control-safe, opaque nonempty `incarnationId` of at most 256 characters. Every non-success includes the same identity beside its last real actor state and version. A changed ID makes comparison explicitly unordered.

`UC02` is resolved by the exact 85-cell resolver and the six bounded public error codes in `syncControlErrorRegistry`: `sync.control-rejected`, `sync.control-failed`, `sync.control-cancelled`, `sync.control-timeout`, `sync.control-idempotency-conflict`, and `sync.control-capacity`. Messages, strict details, reasons, operation applicability, last observation, idempotency retention, and handle cleanup are fixed.

Candidate.6 still requires independent exact-digest review. It has no remaining UC01/UC02/R189-06/R189-07/R189-14/R189-15/R189-16/R189-17 design ambiguity.
